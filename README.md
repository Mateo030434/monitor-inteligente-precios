# Monitor Inteligente de Precios

## Descripción

Este proyecto analiza la variación de precios de cuatro productos utilizando Python y pandas.

El programa compara el precio anterior con el precio actual y calcula el porcentaje de variación.

## Clasificación

El programa clasifica los productos como:

- SUBIÓ
- BAJÓ
- ESTABLE

## Productos analizados

- Arroz 2kg
- Aceite 1L
- Leche 1L
- Café 400g

## Tecnologías utilizadas

- Python
- Pandas
- Google Colab
- GitHub
- GitHub Actions

## Estructura del proyecto

- `src/analizar_precios.py`: contiene el código del análisis.
- `requirements.txt`: contiene la dependencia pandas.
- `.github/workflows/`: contiene la automatización del proyecto.

## Objetivo

Utilizar programación aplicada a la Inteligencia de Mercados para analizar cambios de precios y obtener información que pueda apoyar el análisis del mercado.
